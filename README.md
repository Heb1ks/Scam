# Scam Platform

## 1. Project Relevance
In recent years, the online betting industry has experienced explosive growth, driven by the digitalization of sports and the rapid development of esports. Traditional betting methods are giving way to high-tech platforms that offer instant access to global events.

The relevance of our project, **Scam**, is based on three key factors:

- **Technological Demand:** Modern users require real-time responsiveness and high transaction speeds. By using the Go programming language, we ensure high performance in handling concurrent requests, which is critical during peak loads like major tournament finals.
- **Esports Integration:** Unlike conservative platforms, we aim to integrate esports disciplines (CS2, Dota 2, League of Legends), which are becoming dominant among the younger demographic.
- **Security and Trust:** With the rise of cyber threats, building a robust system with a clean monolithic architecture and secure JWT authentication is a priority for users trusting a platform with their funds.

- **Simplified UX:** Our focus is on a "clean" design where the path from selecting a match to placing a bet takes the minimum number of clicks.  
- **Go-Powered Backend:** Using Go’s concurrency model allows us to handle thousands of active bets and live odds updates more efficiently than traditional legacy systems.

## 3. Target Audience
Our platform targets two primary segments:

1. **"Analysts" (Ages 25–45):** Experienced bettors who value odds accuracy, detailed history, and fast withdrawals.  
2. **"Esports Enthusiasts" (Ages 18–30):** A younger generation that values speed, modern UI, and the ability to bet on digital sports on the go.

---

## 4. Planned Features
To deliver a functional MVP, the following features will be implemented:

- **User Management:** Secure registration, login (JWT-based), and profile management.  
- **Wallet System:** Virtual balance handling, including deposit/withdrawal simulations and transaction history.  
- **Event Line:** A comprehensive list of upcoming and live matches categorized by sport.  
- **Betting Engine:** Logic for placing single bets, validating user balance, and automatic result processing.  
- **Admin Dashboard:** Tools for administrators to create matches, set odds, and settle match results.
